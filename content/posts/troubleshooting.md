# 障害対応・トラブルシューティングメモ

## １．WSL起動時にWindows領域（/mnt/c/Users/...)に迷い込む
- **現象**: ターミナル起動時に'ls -l'を実行した際、'NTUSER.DAT'や'Documents'などWindows側のファイルが一覧表示された
- **原因**: WSL起動時のカレントディレクトリがLinuxのホーム領域('~')ではなく、Windowsのユーザー領域('/mnt/c/User/rkh93')になっていたため。
- **対応方法**: 'cd' コマンドを単体で実行し、Linuxホーム領域に戻った。

## ２．Hugoで新規記事がブラウザに表示されない
- **現象**: 記事を作成して'hugo server' を実行しても、ページが表示されない。
- **原因**: Hugoの使用上、記事ファイルの先頭にある'draft:true'（下書き状態）が有効だと通常ビルドで除外されるため。
- **対応方法**: 'draft:false' に変更するか、確認時に'hugo server -D'オプションを付けて実行した。

## ３．ディレクトリ指定エラー(No such file or directory)
- **現象**: ファイルを開こうとすると、『No such file or directory』と表示される。
- **原因**: 意図したフォルダ（'my_website'等）と異なる場所から相対パスでコマンドを実行したため。
- **対応方法**: 'pwd' で現在地を確認し、正しいディレクトリへ'cd' で移動してから操作を行った

## ４．"localhost:1313" に接続できない
- **現象**: ブラウザで'http://localhost:1313/'にアクセスした際、ページに到達できなかった
- **原因**: WSL側でローカル開発用サーバーが起動していないため（WSLで'hugo server'を起動するコマンドを打ち込んでいないため
- **対応方法**: ターミナルでコマンド入力（hugo server -D'を入力→Enter→Edgeで閲覧可能になった

## ５．CI/CD導入時のコマンド入力の際のエラー
- **現象**: WordからWCLにコピペしたらコマンドの末尾（各行）に赤ハイライトが表示されてた
- **原因**: 赤ハイライトの正体は全角スペース
- **対応方法**: 全角スペースを削除  ※　半角なら問題なし

## ６．Githubへのアップロードコマンド時のエラー
- **現象**: 'git push origin main'入力後'without 'workflow' scope' エラー表示
- **原因**: Personal Access Token に'workflow' 権限がない(YAMLファイルの編集をアップロードするのに井阿万でのトークンでは権限がないからエラーが出た
- **対応方法**: GitHub内でトークンの権限設定を変更(repoだけじゃなくworkflowにもチェックを入れる)→再度git push origin main を実行→完了

## ７．'Could not resolve host:github.com'エラー表示
- **現象**: 'git push origin main' 後にユーザーネームを聞かれなかった
- **原因**: PC、WCLが一時的にネット接続が切れてた
- **対応方法**: Wi-Fi再接続→再度実行→ユーザーネーム聞かれる(OK)→完了

## ８．CSSデザインが反映されてない
- **現象**: ローカルサイトにデザイン変更が反映されてない
- **原因**: 使用しているテーマに合わない設定・ファイル配置をしていたため(PaperMod用の配下にコマンド入力をしていた)
- **対応方法**: 'hugo.toml'にPaperMod用の設定を追加→カスタムCSSの配置場所を変更しPaperModのHTML構造に合わせたセレクタに修正

## ９．GitHub Actionのビルド失敗(GitHubのダッシュボード上で赤×マークが表示)
- **現象**: コマンドはうまくいったがビルド失敗
- **原因**: '.github/workflows/hugo.yml'内のHugoインストール用URLに不要なスペースがあったため
- **対応方法**: 'workflows/hugo.yml'内のコマンドを公式の動作保証されたアクションに編集（シンプルな設定に書換え）→Push

## １０．本番サイト（スマホ版）でのエラー
- **現象**: スマホ版や本番サイトでテキストのみの表記/クリックしてもExample Domainへ遷移する
- **原因ん**: 'hugo.toml'内のbaseURL(サイトURL)が初期設定のままで参照が崩れる、リンクが見つからない状態だったため
- **対応方法**: baseURLの変更→Push
